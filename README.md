A Python program that prints one funny line explaining the glass in five seconds for make.fun's "Five Seconds to Explain the Glass" bounty.

## The line

> It's half full of water and half full of air — so it's always full, and the only thing half empty is the argument about it.

## Run it

```sh
python3 main.py
```

Prints the one-liner (123 characters, one line) to stdout. Standard library only, no network, no files read or written.
